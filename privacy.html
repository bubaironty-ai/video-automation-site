Privacy Policy

Last updated: 21 November 2026

AI Video Uploader is a personal tool operated by Snehashis Mondal. It is used only with the owner's own accounts.

What it accesses

With the owner's permission it uses the YouTube, Facebook and Instagram APIs to upload videos, titles, descriptions and thumbnails to the owner's own channel and pages.

What it stores

Only the access tokens needed to upload, kept in a private GitHub repository's encrypted secrets. No data about other people is collected, sold or shared.

Google API data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google, Facebook or Instagram account security settings.
